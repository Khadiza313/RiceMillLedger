# RiceMillLedger
RiceMillledger is a digital Notebook website for rice mill shop owners. It includes tracking and managing stock, purchases, the milling process, sales, accounts, report, etc. The main objective of RiceMillLedger is to digitalize the current notebook system of mill shops so that shop owners can easily update RiceMillLedger from anywhere—without the hassle of carrying and storing physical notebooks and performing manual calculations.

**Tech-Stack**
---
- Frontend: HTML, CSS, Javascript
- Backend: Node.js, Express
- Database: MongoDB

**Core features (MVP)**
---
- User registration and login/logout
- Stock Updates
- Purchases
- Milling updates
- Sales
- Accounts
- Report
- Seller info
